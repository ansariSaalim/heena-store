# Heena Store

Demo e-commerce web app for roasted peanuts, chana (chickpeas) and dry fruits.

- Payment by UPI only (QR code, UPI ID, UPI app link)
- Cash on Delivery disabled
- Single file: `index.html`, no build step

To use a real UPI ID, edit the `UPI_ID` line in `index.html`.

Live: https://ansarisaalim.github.io/heena-store/
